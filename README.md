# 🎮 Neon Tic Tac Toe Pro

A vibrant, modern, and high-energy Tic Tac Toe game powered by **Node.js** and **Express**. This project features a polished UI with animated gradients, neon effects, and a sleek glassmorphism design.

## ✨ Features

- **Dynamic Background:** Eye-catching animated CSS gradients.
- **Modern UI:** Glassmorphism and neon glow effects for a premium feel.
- **Node.js Backend:** Served via a lightweight Express server.
- **Responsive Design:** Playable on various screen sizes.
- **Interactive Gameplay:** Hover effects and tactile feedback.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher recommended)

### Installation

1. Navigate to the project directory:
   ```bash
   cd ai
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Game

Start the local server:
```bash
node app.js
```

Open your browser and visit: [http://localhost:3000](http://localhost:3000)

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid, Animations)
- **Backend:** Node.js, Express
- **Scripting:** Python (Original CLI version included)
